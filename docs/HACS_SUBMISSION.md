# HACS installation and catalog status

HAMediaConnect can be installed as a custom HACS repository; see [installation instructions](HA_INTEGRATION_INSTALL.md).

The Android APK is downloaded separately from [GitHub Releases](https://github.com/emarrero-personal/HAMediaConnect/releases). HACS installs only the Home Assistant integration.

Official catalog submission and release approval are maintainer tasks. See the [Maintainer handbook](MAINTAINER.md) for validation, branding, and submission procedures. Do not interpret this page as confirmation of official catalog inclusion.
